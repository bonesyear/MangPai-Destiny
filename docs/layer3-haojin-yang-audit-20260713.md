## 4. 剩余 ❌ 的共性原因（5类根因）

### 根因A: 层功/财命/官命不识别用神忌神方向 — 制用神被当成功(最大缺口)
引擎把「劫刃制财」「官杀制比劫」一律按做功/富/贵计，**不看所制者是忌神(吉)还是用神(凶=破财)**。
- **第9期(官司破财)** 最典型: 层功 **L4 极富极贵 score=100 净**，金标准=官司输+大破财+清家荡产。郝断明言「用神是火(午)，卯破午=用神被破=破财」；引擎却把午火当忌神劫刃制之=L4。这是**层功脱节 bug 的新形态**。
- **第1期(破财)**: 层功L3→财命富亿级，金标准=戊辰年破财打官司。
- **第2期(赔钱)**: 层功L3→巨富，金标准=赔六万。
- **第8期(贪财坐牢)**: 层功L2→官命科级实权，金标准=坐牢(反局)。
- **第4期(乞丐)**: 层功L2 中富中贵，金标准=乞丐(财为忌见财为害)。

→ **P0**: 财命/官命/层功 必须接入「用神/忌神方向」判定。制用神=破财凶，制忌神=得财吉。
  当前 `gongliang` 无用神判定，`caiming`/`guanming` 只看官杀有根/财星有无，不辨方向。
  依赖 `zhengfan`(反局) 检测 — 但第9期正反=「局未定」(漏判)，第8期=反局✅但层功/官命未消费反局信号降档。

### 根因B: 官命 over-fire (is_guanming=True 仅凭官杀有根)
- 第8期(坐牢)/第9期(破财)/第2期(运输)/第4期(乞丐)/第10期(找二婚): 一律 is=True + 处级/科级实权。
- 官杀地支有根即判官命，不结合「反局/忌神/破财/坐牢」降档或否决。
→ **P1**: `guanming` 须消费 `zhengfan`(反局)、`caiming`(破财)、墓库(官杀入墓) 信号做否决/降档。

### 根因C: 职业 military over-fire
- 第2期(赔媳妇, 开车运输)/第9期(官司破财, 普通人): 误判军警/军阀/武职。
- `_score_military`(官杀成势≥3柱+2/七杀透+1/羊刃+1…) 对「官杀成势」敏感，但官杀成势≠武职(可能是坐牢/破财的忌神)。
→ **P1**: military 评分须 gating 于「官命 is=True 且非反局/破财」(消费根因A/B信号)，否则忌神官杀成势误触。

### 根因D: 阎锡山 L3 非 L4 (Bug2 残留)
- `hua_chengju` gating 过严: 仅当杀印相生为真做功(非auxiliary)才置True→不封顶；
  阎造有制用+墓用→杀印相生被标auxiliary→`hua_chengju=None`→「不净封顶三层」仍咬合→L3。
- 但金标准「半壁天下/都督/掌管山西36年」=L4 极富极贵。
→ **P1**: 化用成局/从杀格路径下，「制不净封顶」不应适用(化用非制局)。
  当前 `if zhi_jing=='不净' and level>3 and not hua_chengju` 的 `hua_chengju` 须放宽到「7d触发(纯化用路径)」而非「杀印相生为真做功」。

### 根因E: 婚姻 duohun 漏判 + 子息 has_zixi 一律 False
- **婚姻**: 第5期(两次婚)/第7期(三婚) `duohun=False` 漏判多婚；第1期(有子)却 over-fire 多婚/独身。
  `duohun` 检测对「配偶星被破/入墓/盖头劫财」(第10期卯被两子破=破货)未识别。
- **子息**: 10例 `has_zixi` **一律 False/有阻** — 系统性过悲。仅第7期(金标准无子)命中；
  第1期(金标准有子+怀胎)误判无子。`detect_zixi_youwu` 对「子息宫受冲/原神被破」触发阈值过低。
→ **P1**: duohun 补「配偶星被破/盖头劫财/入墓」检测；zixi `has_zixi=False` 阈值收紧(需多条件共振，非单条件)。

## 6. 方法论注记

- **金标准来源**: `mangpai/docs/duan-books/mingli-zhenbao-50qi.txt` 原文逐字摘录(第1/4/5/9/10/12/14/23期)。

- **应期维度**: 仅评有运/年输入的6例；无运输入的4例(6,7,8,10)引擎正确返回 yq=None，不计。
- **N/A 处理**: 金标准未涉及该维度的 case 不计入分母(如第3期无婚姻断语)。
- **Bug3 判别器注**: 第4期赔媳妇 engine=military，memory[[calib-zhenbao-3bug-fix-2026-07]]记为「非regression实更准(庚坐申禄+丑金库=身有力抗杀=权贵)」；但**以郝金阳原断「开车搞运输赚钱，申为传送主车」金标准论，命主是司机/运输非武职**，故本轮按金标准判 ❌。引擎内部理法自洽≠与原断一致。
