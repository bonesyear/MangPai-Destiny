## 背景
`output/` 下的评估管线（历史批次逐步累积）存在大量重复：
- `_n2_eval.py` / `_t3_eval.py` 的 runner / prompt 组装**高度重复**
- `_n2_calibrate.py` / `_t3_calibrate.py` / `_v3_calibrate.py` 的**一致率/翻转召回/达标判定三份重复**
- `_n2_sample.py` / `_v3_sample.py` **抽样逻辑重复**
- `_w4_sample.py` / `_w5_crosscheck.py` 的 `engine_fe`/禁词扫描/无信号判定**跨脚本重复**

**风险**：口径漂移——同一指标在三个脚本里有三种实现，改动时漏改一处 → 评估结论不一致（历史已有教训：`_n2_analyze` 统计口径 bug、`cost_usd` ×7.2 错折算）。
