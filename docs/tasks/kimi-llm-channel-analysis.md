## 背景：拟建「LLM 推演通道」

现状：引擎是确定性规则引擎（客观层计算 + 主观层判定 + 模板叙述），三维留出集 66.67/74.24/44.23，pytest 499。

拟建结构：
```
八字 → 确定性引擎（做功/体用/层功/财官职业判定/大运流年特征）
        ↓ 特征 JSON（结构化可验证）
     LLM（DeepSeek thinking + json mode）
        ↓ 段氏风格叙述（JSON schema 校验）
     性格/事业/财运/婚姻/应期解释
```
设计要点：LLM 只叙述引擎已判定的内容（依据校验防幻觉）、JSON 结构化输出、不碰计算链（引擎零改动）。
