## 三、维度交付口径裁定（建议）

**裁定建议：保持特征层+文档口径，不进五维叙述。** 理由：

1. **性质不同**：五维（性格/事业/财运/婚姻/应期）背后引擎有判定/档位（财五档、官是否、职业桶），L2 校验器措辞强度契约绑定档位；qianyi/xiangmao 自承「中置信度/或然/marker 层无档位」，无档位可锚，进叙述则 LLM 措辞强度失去校验锚点，放大风险不可控。
2. **红线缺口**：「不出出国级断语/不出美丑结论词」目前仅引擎层+哨兵锁；LLM 通道校验器无等价口径，进叙述即开红线口子。要进需先立 LLM 层红线校验 + S1 复测（E6/E7 级工作量），不值。
3. **现有通道已够**：特征 JSON 经 selectors（41）进 payload，basis 契约允许 LLM 引用 `qianyi.*`/`xiangmao.*` 真实路径——特征层消费已通，不缺交付能力。
4. **宣称口径建议**：对外口径=「新三维度（zinv/qianyi/xiangmao）为特征层供给，五维叙述维持不变」；写入 KB/收工记录即闭环。若日后进叙述，前置条件 = LLM 红线校验 + S1 复测 + 该维 heldout 抽样验证。
