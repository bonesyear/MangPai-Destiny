## 二、三条规则（每条：书机制 → 实现 → 落点）

### 规则1「三种功≠三层功」通则扩展（副总案，理象学:6898-6912）

- **书机制（细读 :6890-6912）**：书曰「日主丁火没有功，弃之不看，看丑土。寅丑暗合，酉丑半合，子丑又合，丑有三种合」——三种功全出自**日支丑一字**之三合；「虽然看起来有三种不同的功，但论功量只有一层，不是三层功」。两条机制：(a) 日主无功弃之不看；(b) 同一做功主体（一字）经合族所出多种功，论功量只一层。
- **实现**（gongliang.py，中文注释带行号）：
  - (a) 克链剔日主边：`_apply_gong_point_rules` 块 7 建链前滤去 `from_pos/to_pos == 'day_gan'` 之克边（日主自克=我去取财之意向，既有 :1490 先例；日主被克=七杀攻身，皆日主之事非命局做功）。19 案复扫：仅副总链 2→1 跨 +1 阈值；例八/奥纳西斯/阎锡山/普例二三四 1→0（链本低于阈值，**points/level/score 不变**，仅 chain_length 输出字段 1→0）。
  - (b) 日支合中心并计：同制位==day_zhi 且日支涉≥3 合（地支合/暗合/半合，同 `zuogong_detect._apply_he_center_skip` 既有口径）→ 同制 +2 改 +1、七杀当财不重复计层（reasons 明载「同制族并计」）。19 案复扫：日支涉≥3 合者**仅副总**（普例二 2、李嘉诚 2）。
- **落点**：副总 4.5→**1.5 点 → L1**（合中心并计1 + 月令0.5；克链已剔）✓ 书一层。

### 规则2「天干坏之」否决（差例三，理象学:6354-6358）

- **书机制（细读 :6340-6360）**：「看地支有火与燥土成比禄之势，冲制亥水财星，似乎功量很大；然再看天干**亥中甲乙并透，来制日主**，所以地支之制财官之局，**全被天干坏了**。一生没有富贵，农村打工为生」。对照紧邻例四（:6360-6365「庚金透干无制，制局之功明显不彻底，所以功量不大」）——书分两档：官杀**并透**制日主=全坏（无功）；一般透干无制=不彻底（功量不大）。「并」字为关键：正官与七杀同透（官杀混杂）。乾隆造官杀并透（丁官+丙杀）而帝王四层——判别闸=**制净与否**：制净者被制方根尽、透干官杀为虚不能为害；制不净（被制方残存反扑）方成立否决。
- **实现**：两段式——rules 段结构候选（制局目标支藏干含官杀 + 官杀并透混杂（阴阳双透，`_YANG_GANS` 判正/七杀）+ 日主无印透干化杀，记 `_tg_huai_struct`/`_tg_huai_note`/`_yuanshen_family_pts` 同制族累计）；caps 段制净闸后确认（`_tg_huai_struct and zhi_jing=='不净'`）→ 同制族计分（同制/制墓库/七杀当财/库源连墓）整族撤销 + **level 判 0（无功）**。与「虚透/空亡」打折关系：打折=制不净降层调节（先），本条=结构否决（后）——否决成立则层功直判 0，不重复计。19 案复扫：**唯一命中差例三**（乾隆候选过但 zhi_jing=净被闸回；例八壬壬纯杀双透非混杂；李嘉诚/例七/奥纳西斯透干官杀非同制位藏干或单透）。
- **落点**：差例三 4.5→1.5 点（同制族 3 点撤销）→ **L0 无功**（tier_name='无功'，score=0）✓ 书「一生没有富贵」。
- **附带补缺**：`_SCORE_BASE` 补 `0: 0`——G1 仅补 `_SCORE_BAND` 0 分支，空数据早退路径不经 `_compute_score` 故未暴露；本批否决为首个中管道 0 态，补齐完成 G1 既定意图。

### 规则3 月令做功整层 vs 半层裁断（慈禧案，理象学:10595-10611）

- **书机制（细读 :10600-10611）**：书自账=双层（制去杀与杀的原神）+ 包局（禄星禄库包围又加一层）+「再加之本身月令见印，**是一个强有力的印**」=共四层——书于此把**月令见印**计为整层；对照 gaoji:866-870 法则7「月令做功加半层功」（gaoji 为今人重编本权重低，理象学正文案例为准）。条件取书的特定情形（最小波及）：**月令本气为日主之印 且 月令入三合局成势**（「强有力」之据：既当令又入局成势）。普例四/普例五（月令辰=庚日之印但子辰半合不成局）维持 +0.5 不越书（普例四 L2 书判两层）。
- **实现 A（月令见印整层）**：块 7e 增分支——`_yue_wx == 印五行 and 月令 ∈ 三合局（三支全）` → +1 整层，否则维持 +0.5。19 案复扫：仅慈禧命中。
- **实现 B（封顶通路）**：慈禧 7.5 点本已 raw4，唯制不净（食伤透干）封顶 3——书明示三合制杀库「将丑土连其丑中的杀星**全部制死**…共四层功」=制之彻底，透干泄秀书未视为不净。比照既有奥纳西斯先例（方局围制+制库，:6470-6474，不净封顶不适用），增「**三合成势围制+制库**」同例豁免（`_sanhe_zhiku = san_he_formed and _zhiku_tombs`，reason 别载书证）。19 案复扫：san_he_formed=True 者仅慈禧。
- **落点**：慈禧 7.5→8.0 点（月令 0.5→1）→ raw4 → 豁免不净封顶 → **L4** ✓ 书四层。
