# 隐私说明 · Privacy Statement

> 项目：MangPai · 盲派命理推演系统（Chinese Bazi Analysis Engine）
> 版本：v1.1 ｜ 生效日期：2026-08-28
> 适用范围：本仓库的全部使用方式——Python 库调用、CLI 排盘、自托管服务，以及基于本系统的任何前端接入（含飞书机器人示例实现）

---

## 一、设计原则

本系统按**隐私优先（privacy-by-design）**构建，遵循三条核心原则：

| 原则 | 含义 |
|------|------|
| **本地优先** | 命理推演是确定性逻辑运算，**全部在本地完成**，不依赖任何外部服务 |
| **默认零外发** | 引擎自身不联网、不上传、无遥测；一切网络行为均来自**显式可选组件** |
| **无状态** | 不建用户档案、不落盘存储、不记录使用历史——处理完即弃 |

**数据主权归部署者**：本系统为开源、自托管项目，运行在你自己（或你的部署方）的机器上，生辰数据始终处于你的控制范围内。仓库维护者不接触、不收集、不存储任何使用者数据。

---

## 二、系统处理什么数据

排盘所需的最小输入集：

| 信息项 | 用途 | 必填 |
|--------|------|------|
| 出生日期（阳历/农历） | 排四柱 | 必填 |
| 出生时刻 | 定时柱、大运交运 | 必填 |
| 性别 | 定大运顺逆 | 必填 |
| 出生地（城市名/经度） | 真太阳时校正 | 选填 |

**系统不收集也不要求**：姓名、手机号、身份证号、邮箱、账号、位置轨迹、设备信息，或任何与排盘无关的个人数据。

## 三、数据流向（分层说明）

```
   输入：生辰 / 性别 / 出生地
              │
              ▼
   ┌────────────────────────────────────┐
   │  ① 引擎层 —— 本地，零外发            │
   │     排盘 · 做功 · 十神 · 大运流年     │
   │     应期 · 层功 · 财命官命 · 婚姻等   │
   │     纯逻辑运算：不联网、不落盘        │
   └────────────────┬───────────────────┘
                    │ 结构化结论
                    ▼
   ┌────────────────────────────────────┐
   │  ② 叙事层 —— 可选组件，默认关闭       │
   │     将八字 / 性别 / 经度提交 LLM API  │
   │     生成自然语言解读                  │
   │     可关闭 · 可替换 · 可审计          │
   └────────────────┬───────────────────┘
                    │ 叙述文本
                    ▼
              输出：CLI / API / 前端
```

### ① 引擎层（默认启用，零外发）

全部命理推演均为**本地确定性计算**：四柱排盘、节气、藏干、长生、十神、冲合刑害、做功识别、墓库、神煞、大运流年、应期、层功量化、财命官命、婚姻学历、职业取象等。

- ❌ 不发起任何网络请求
- ❌ 不写盘、不建数据库；日志中不含生辰数据
- ❌ 无遥测，不向维护者回传任何使用数据

**只使用引擎层时，数据不出本机。**

### ② 叙事层（可选组件，显式配置后生效）

"引擎结论 → 自然语言解读"由 LLM 通道完成。该组件具备四个特性：

- **默认不启用**：未配置 API Key 时，系统仅输出引擎的结构化结论
- **可关闭**：设置 `MANGPAI_USE_LLM=0`（飞书接入层旧名 `FEISHU_USE_LLM` 仍兼容）后完全走引擎直出，零外发
- **可替换**：通道兼容 OpenAI 风格协议，通过 `MANGPAI_LLM_BASE_URL` / `MANGPAI_LLM_MODEL` / `MANGPAI_LLM_API_KEY` 可指向任意自建或自选服务（本地模型、私有部署、其他厂商；严格兼容服务另设 `MANGPAI_LLM_THINKING=0`），具体配置见 README「配置你自己的 LLM」节与 `.env.example`
- **可审计**：源码完全可见（`subjective/llm_backend.py`、`llm_channel.py`），提交内容的边界透明

**开启时提交的内容**：八字干支、性别、出生地经度、系统提示词（命理规则与输出格式要求）。

**不会提交**：姓名、账号、历史对话或任何身份标识。

**第三方服务**：叙事层可对接任意第三方 LLM 服务，其数据处理行为适用该服务自身的条款与隐私政策，本系统无法控制。对隐私敏感的场景，建议改用本地模型或关闭叙事层。

## 六、使用者的控制权

| 你的目标 | 做法 |
|---------|------|
| 完全零外发 | 只使用引擎层（不配置 LLM），或显式关闭叙事层 |
| 数据不经第三方 | 将叙事层指向本地模型或私有部署（设 `MANGPAI_LLM_BASE_URL`/`MANGPAI_LLM_MODEL` 指向本地端点，如 Ollama，另设 `MANGPAI_LLM_THINKING=0`；操作见 README「配置你自己的 LLM」节） |
| 不提供出生地 | 出生地为选填；省略时按标准时排盘（真太阳时校正精度略降） |
| 自行审计外发内容 | 阅读 `subjective/llm_prompt.py`（payload 组装）与 `llm_backend.py`（请求发送） |
| 要求删除数据 | 无需操作——系统本就不存储 |

## 七、日志与运维（自托管部署注意）

- **运行日志**：仅记录运维信息（消息 ID、异常类型），不含生辰数据
- **诊断信息**：异常堆栈仅用于故障排查，不涉及使用者身份
- **重放保护**：防止重复处理时短暂保留消息 ID（非内容），并滚动清理
- **部署方责任**：若你自托管并向他人提供服务，你即为该场景下的数据处理者，建议向使用者明示本节内容

## 八、内容边界与免责

- 本系统输出属于**传统命理推演**（段建业/郝金阳盲派体系），归文化研究与学术推演范畴，**不构成人生决策、医疗、法律或投资建议**
- **不提供**死亡预测、疾病诊断、胎儿性别推测等敏感内容；系统内置安全过滤，涉及重疾或死亡类表述会触发拦截
- **引擎结论与模型叙述性质不同**：引擎输出（四柱、大运、做功、层级等）为确定性计算结果；开启叙事层后，解读文本由大模型生成，可能存在表述偏差或幻觉，请区分看待
- 若你正处于**重大人生决策或心理困境**，请咨询相应领域的专业人士
