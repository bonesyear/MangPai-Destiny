# 隐私说明 · Privacy Statement

> 项目：MangPai · 盲派命理推演系统（Chinese Bazi Analysis Engine）
> 版本：v1.0 ｜ 生效日期：2026-08-28
> 适用范围：本仓库的全部使用方式——Python 库调用、CLI 排盘、自托管服务、以及基于本系统的任何前端接入（含飞书机器人示例实现）

---

## 一、设计原则

本系统按**隐私优先（privacy-by-design）**构建，核心原则三条：

| 原则 | 含义 |
|------|------|
| **本地优先** | 命理推演是确定性逻辑运算，**完全在本地完成**，不依赖任何外部服务 |
| **默认零外发** | 引擎本身不联网、不上传、不遥测；任何网络行为均为**显式可选组件** |
| **无状态** | 不建用户档案、不落盘存储、不记录使用历史——处理完即弃 |

**数据主权归部署者**：本系统为开源/自托管项目。你（或你的部署方）在自己的机器上运行它，生辰数据始终在你的控制范围内。仓库维护者不接触、不收集、不存储任何使用者的数据。

---

## 二、系统处理什么数据

排盘所需的最小输入集：

| 信息项 | 用途 | 必填 |
|--------|------|------|
| 出生日期（阳历/农历） | 排四柱 | 必填 |
| 出生时刻 | 定时柱、大运交运 | 必填 |
| 性别 | 定大运顺逆 | 必填 |
| 出生地（城市名/经度） | 真太阳时校正 | 选填 |

**系统不收集也不要求**：姓名、手机号、身份证号、邮箱、账号、位置轨迹、设备信息，或任何与排盘无关的个人数据。

## 三、数据流向（分层说明）

```
                    ┌─────────────────────────────────────┐
   输入（生辰/性别/出生地）──▶│  ① 引擎层（本地，零外发）           │
                    │  排盘 · 做功 · 十神 · 大运流年 · 应期  │
                    │  纯逻辑运算，不联网、不落盘           │
                    └───────────────┬─────────────────────┘
                                    │ 结构化结论
                    ┌───────────────▼─────────────────────┐
                    │  ② 叙事层（可选组件，默认关闭）       │
                    │  将八字/性别/经度提交 LLM API        │
                    │  生成自然语言解读                    │
                    │  —— 可关闭 / 可替换 provider         │
                    └───────────────┬─────────────────────┘
                                    │ 叙述文本
                                    ▼
                              输出（CLI / API / 前端）
```

### ① 引擎层（默认，零外发）

全部命理推演——四柱排盘、节气、藏干、长生、十神、冲合刑害、做功识别、墓库、神煞、大运流年、应期、层功量化、财命官命、婚姻学历、职业取象等——均为**本地确定性计算**：

- ❌ 不发起任何网络请求
- ❌ 不写盘、不建数据库、不留日志（含生辰）
- ❌ 不遥测、不回传、不校验授权

**只使用引擎层时，数据不出本机。**

### ② 叙事层（可选，显式开启才生效）

"引擎结论 → 自然语言解读"由 LLM 通道完成。该组件：

- **默认可不启用**：不配置 API Key 时，系统仅输出引擎结构化结论
- **可关闭**：`FEISHU_USE_LLM=0`（或对应配置项）→ 完全走引擎直出，零外发
- **可替换**：通道协议兼容 OpenAI 风格 API，可指向任意自建/自选服务（本地模型、私有部署、其他厂商）
- **可审计**：源码可见（`subjective/llm_backend.py` / `llm_channel.py`），提交内容边界完全透明

**开启时提交的内容**：八字干支、性别、出生地经度、系统提示词（命理规则 + 输出格式要求）。

**不提交**：姓名、账号、历史对话、任何身份标识。

**第三方归属**：若你配置了第三方 LLM 服务（默认适配 DeepSeek），该服务的处理行为适用其自身条款与隐私政策，本系统无法控制。**建议做法**：对隐私敏感的场景使用本地模型，或关闭叙事层。

## 四、本系统不做的事

| 事项 | 说明 |
|------|------|
| ❌ 不建用户档案 | 无账号体系、无登录、不记录"谁问过什么" |
| ❌ 不落盘存储 | 排盘处理后即弃；不写数据库/文件 |
| ❌ 不用于模型训练 | 使用者的生辰与对话不进入任何训练集 |
| ❌ 不向第三方出售/共享 | 除你显式开启的叙事层外，无任何外发 |
| ❌ 不做用户画像 | 无广告、无行为追踪、无推荐系统 |
| ❌ 不主动联系 | 不做推送、营销或事后触达 |

本仓库是**引擎源码 + 学术资料**，其内容性质如下：

| 仓库内容 | 性质 |
|---------|------|
| 引擎源码（`mangpai/`、`foundation/`） | 代码，无个人数据 |

## 六、使用者的控制权

| 你想要的 | 怎么做 |
|---------|--------|
| 完全零外发 | 只用引擎层（不配置 LLM），或显式关闭叙事层 |
| 数据不经第三方 | 将叙事层指向本地模型 / 私有部署 |
| 不提供出生地 | 出生地为选填；省略时按标准时排盘（真太阳时校正精度略降） |
| 自审外发内容 | 阅读 `subjective/llm_prompt.py`（payload 组装）与 `llm_backend.py`（请求发送） |
| 要求删除 | 无需操作——系统本就无存储 |

## 七、日志与运维（自托管部署注意）

- **运行日志**：默认仅记录运维信息（消息 ID、异常类型），**不含生辰数据**
- **诊断信息**：异常堆栈用于故障排查，不涉及使用者身份
- **重放保护**：防重复处理时短暂保留消息 ID（非内容），并滚动清理
- **部署方责任**：若你自托管并向他人提供服务，你是该场景下的数据处理者——建议保留本节说明并对使用者可见

## 八、内容边界与免责

- 本系统输出为**传统命理推演**（段建业/郝金阳盲派体系），属文化研究与学术推演范畴，**不构成人生决策、医疗、法律或投资建议**
- **不提供**：死亡预测、疾病诊断、胎儿性别推测等敏感内容；系统内置安全过滤，涉及重疾/死亡类表述会触发拦截
- **引擎结论 vs 模型叙述**：引擎输出的客观结果（四柱/大运/做功/层级等）为确定性计算；开启叙事层后，解读文本由大模型生成，可能存在表述偏差或幻觉，**两者性质不同，请区分看待**
- 若处于**重大人生决策或心理困境**，请咨询相应领域的专业人士
